## What I build

**AI runtimes**  
Tool-using assistants, provider routing, execution boundaries, approvals, memory, and observable agent behavior.

**Product systems**  
End-to-end flows with explicit state ownership, authentication, persistence, recovery, and real operational behavior.

**Android + device control**  
Phone-first software that keeps known device actions deterministic and gives reasoning a clear boundary.

**Web intelligence**  
Search, retrieval, extraction, parsing, and analysis pipelines designed to stay inspectable instead of becoming a black box.
